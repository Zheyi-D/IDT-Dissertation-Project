List of Dissertation Project
================================

这是一个完全本地、离线的项目浏览工具（无需联网、无需服务器）。

使用方式
--------
1. 双击打开 index.html（建议用 Chrome / Edge）。
2. 即可浏览 391 个 2026-27 学年机械工程系项目（去重后数量；
   学校系统原始列表显示 392 条，其中一条为服务器重复数据）。
3. 单击任意一行查看该项目的完整详情与详细说明。

功能
----
- 顶部搜索框：按 编号 / 标题（中英）/ 方向 / 公司 / 导师 / 审核人 搜索
- 类型筛选：公司项目（61） / 导师个人项目（330）
- 方向筛选：按 14 个学科大类（人工智能、机器人、计算机与软件、
  无人机与航空、电子与传感、控制与自动化、机械与力学、设计与制造、
  材料、能源与热流体、流体与海洋、生物医学与健康、管理与教育、其它），
  选项显示“中文 / English”并带命中项目数
- 导师筛选：下拉选择
- 列表分页：默认每页 50 条，可在表格下方修改每页条数（输入数字或用
  10/20/50/100/200 快捷按钮），上一页/下一页/页码跳转
- 收藏：点击行首或详情弹窗中的 ★ 收藏/取消；收藏项自动置顶并高亮；
  勾选“只看收藏”可单独查看收藏；收藏数量实时显示
- 收藏存储：优先存入 Cookie；因 Chrome 禁止 file://（双击打开）写入 Cookie，
  本地双击场景会自动改用浏览器 localStorage，效果一致（换浏览器/清缓存会失效）
- 列表列：★ | 编号 | 类型 | 标题（中/英）| 公司/导师 | 方向

详情弹窗（单击行）内含
----------------------
- 完整标题（中英）、公司/公司导师/校内负责 或 导师/审核人、方向
- 右上角徽标显示“可申请 N 人”（同类型徽标样式），明细中也有可申请人数
- 项目详细说明（学校原站全文）：默认中文（机器翻译），可点「English」切换原文

数据说明
--------
- 数据来源：https://dms.mech.hku.hk/dms2/projectList/displayProjectList
  （Project List “all”视图，2026-09-05 抓取快照，静态数据）
- 中文字段（标题/公司/方向）为机器翻译，仅供参考；
  英文原文始终保留在次要行，详情页附学校全文说明（英文）。

注意事项
--------
- 本工具仅用于本地浏览与选项目参考；真正的项目申请必须在
  学校系统 https://dms.mech.hku.hk 登录后操作。
- “可申请人数”为快照数据（每项目招收名额），不代表当前剩余名额；
  申请前请回原站核对最新状态。

文件组成
--------
- index.html ：界面（自包含，无外部依赖）
- data.js    ：全部项目数据（window.HKU_DATA）
